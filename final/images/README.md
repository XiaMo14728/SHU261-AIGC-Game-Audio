## 三、图片使用与版权（重要）

优先**自己实地拍摄**。如果确实无法拍摄、改用图库图片，必须遵守：

1. 只用明确标注可免费使用的来源（如 Pexels、Unsplash、Pixabay）；
2. **在报告附录里注明：文件名、来源网站、图片来源页 URL、授权方式**；
3. 不要使用搜索引擎图片搜索的结果——那些图片绝大多数有版权，且无法追溯授权。

> 报告里之所以专设"图片来源"一栏，就是为了避免这一项被扣分。

## 四、不要提交

- 原始大尺寸的 RAW / HEIC 原片（转换并压缩成 jpg 后再放进来）
- 带个人隐私信息的截图（桌面、账号、聊天窗口等）
