## 二、基底环境声：拼接与循环点处理（AMB-01）

这是整个作业里技术含量最高的一步。目标：**40 秒、首尾相接听不出来、能无限循环**。

### 2.1 两种起点，先确认你走哪条

| 起点 | 适用情况 | 后续步骤 |
| --- | --- | --- |
| **A. 一段长录音**（首选） | 从 Pixabay 等素材库拿到的 1–5 分钟连续环境声 | **跳过拼接**，直接到 2.3 选段 + 循环点处理 |
| **B. 多段 AI 生成** | 用 AIGC 分段生成（每段 12–15 秒） | 先做 2.2 拼接，再做 2.3 |

**A 路线更省事**，因为长录音里有的是平稳段落可以挑；B 路线之所以要分段，是因为 AI 生成长音频会出现"结构漂移"——开头是树林风声，到后面可能慢慢变成别的环境，所以宁可让 AI 只做短片段，把结构交给 DAW。

### 2.2 拼接（仅 B 路线需要）

1. 把 4 段素材拖进同一轨道，**按顺序首尾相连**放在时间轴上
2. 第一段从 0 秒开始，第二段紧接着放在第一段结束处
3. 每两段之间做**交叉淡化**：把后一段向左拖，让它与前一端**重叠约 1.5 秒**，然后用 `Item → Fade In / Fade Out` 或者直接拖动 item 顶端左右角的淡化手柄，做 1.5 秒的等功率交叉淡化
4. 交叉淡化后听一遍接缝处，**不能听到"啪"或者音量突然塌一下**

### 2.3 选段与循环点处理（关键）

拼接好的总长大约 55–60 秒（A 路线则是几分钟），但我们只要 40 秒。**不能随便截 40 秒就导出**——硬截的声音首尾相接会有一个明显的"跳"。

**先选段**：在整段素材里找一个 **40–60 秒**的区间，满足三个条件：

1. 能量稳定（波形厚度均匀，无忽高忽低）；
2. 无孤立突发事件（没有一声特别突出的鸟叫、喇叭或人声）；
3. 频谱分布全程基本一致（Reaper 里挂频谱图扫一遍）。

选段不理想就换个位置重来——**A 路线的优势就在这里，素材长，容错高**。

正确做法：**"尾巴叠头"交叉淡化**

1. 打上时间选区，从拼接好的素材里选一段音色均匀、没有突发事件的 **42 秒**
2. 设选区起点为 A（比如第 5 秒），终点为 B（第 47 秒）
3. 把 **[40, 42] 这 2 秒**（也就是选区最后 2 秒）复制一份，**粘贴到选区开头 A 的位置**，让它在 A 处与原始内容重叠 2 秒
4. 对这段重叠做 2 秒交叉淡化：复制来的那 2 秒做 `Fade Out`（从满音量到 0），原始内容在 A 处做 `Fade In`（从 0 到满音量）
5. 现在从 A 渲染 40 秒。因为文件的开头是"上一轮的结尾"淡入、文件结尾是"下一轮的开头"淡出，**首尾相接时能量连续**，循环就听不出接缝了

### 2.4 频率处理

基底层三个频段（高频树叶、中低频水声、超低频城市嗡鸣）叠在一起容易在某处堆积：

1. 在轨道上插入 ReaEQ（Reaper 自带）
2. 加一个 **40 Hz 高通**，切掉没用的超低频隆隆声
3. 如果 200–400 Hz 有明显的"浑浊"感，在该频段 **-2 dB** 左右

### 2.5 电平

用 ReaEQ 后面的 **ReaComp** 或直接调 item 音量，把基底做到**听感稳定、峰值约 -6 dBFS**。基底是要长时间铺底的，宁小勿大——到了 Wwise 里还要靠总线调整体平衡。

## 三、间断随机声的处理（SFX-01 ~ 04）

每条 12 个文件，处理流程一致：

1. **裁掉首尾静音**：拖动 item 左右边缘，让声音在起点后 10 ms 内就出现，结束时立刻收尾（AI 素材首尾常带 0.2–0.5 秒静音）
2. **加淡入淡出**：每条都加 **2–5 ms** 的淡入和淡出，防止切口产生"咔哒"爆音
3. **高通 60 Hz**，去掉 AI 常见的低频堆积
4. **Normalize 到峰值 -3 dBFS**：
   - 选中 item → `Item properties`（快捷键 F2）→ Normalize → Peak → **-3 dB**
   - 或者用 `动作列表 → 应用音量包络` 之类的方式
5. **确认时长符合需求**：鸟鸣 1–2 s、水鸟 2–3 s、阵风 2–4 s、铃声 0.5–1 s

## 四、导出设置

`文件 → 渲染`（File → Render），逐项确认：

| 选项 | 值 |
| --- | --- |
| 源 (Source) | Master mix（或选中的 region/item） |
| 渲染范围 | Time selection |
| **采样率 (Sample rate)** | **48000 Hz** |
| **声道 (Channels)** | **Stereo** |
| **格式 (Format)** | **WAV** |
| **位深 (Sample format)** | **24 bit PCM** |
| Normalize | 基底：不勾（已在工程里控制电平）；SFX：可不勾 |
| 文件名 | 严格按 `docs/01` 的命名规范 |
| 目录 | `final/assets/audio/` |

**命名规范回顾**：

```
amb_parklake_loop_01.wav
sfx_bird_chirp_01.wav    sfx_bird_chirp_02.wav    sfx_bird_chirp_03.wav
sfx_water_bird_splash_01.wav  ...  _03.wav
sfx_leaves_gust_01.wav   ...  _03.wav
sfx_bicycle_bell_01.wav  ...  _03.wav
```

> 小写、下划线分隔、不用中文或空格。Wwise 和版本管理对中文文件名都不友好。

## 五、导出自检（自动化）

仓库里有 `final/tools/check-wav.js`，能直接读 WAV 文件头校验格式与时长。导完后运行：

```powershell
$env:Path += ";E:\nodejs"
node "$env:USERPROFILE\Downloads\SHU261-AIGC-Game-Audio\final\tools\check-wav.js"
```

它会逐文件输出采样率、位深、声道数、时长，并标出不符合 **48kHz / 24bit / stereo** 的文件，以及检查"基底是否 > 30 秒"。

**这是提交前的最后一道关卡。** 只要它全绿，格式分就不会丢。

## 六、常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 循环处有"跳" | 首尾能量不连续 | 回到 2.3 重做尾巴叠头 |
| 循环处有"啪" | 波形被硬切 | 加 5 ms 淡入淡出 |
| 导出后是 44.1 kHz | 渲染窗口采样率没改 | 渲染前确认 Sample rate = 48000 |
| 导出后是单声道 | 素材本身是 mono 且没做声道处理 | 渲染 Channels 选 Stereo；或轨道加 ReaSurround 补宽 |
| 音量忽大忽小 | 拼接时四段原始电平不同 | 先逐段 Normalize 到同一峰值再拼接 |
| Wwise 里导入后没有循环 | 循环要在 Wwise 里设，不是 DAW 的功能 | 见 `docs/04` 第三节 |
