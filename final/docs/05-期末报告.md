**核心结论**：

1. AIGC 在游戏音频中的现实定位是"**素材生产与变体供应商**"，而非"艺术决策者"；
2. **离线生成 + 人工精修 + 中间件组织**是当前最务实的工程组合，运行时生成受延迟与算力约束仍属实验性质；
3. 素材从稀缺变为过剩后，Wwise / FMOD 这类"组织与响应"层的重要性**上升而非下降**；
4. 最大的风险不是技术，而是**权利与合规**（训练数据、声音人格权、平台披露要求）；
5. 评估任何 AIGC 音频方案，应看"**平均可用率 + 修复成本**"，而不是"最佳样例"。

### 2. 作品说明

#### （1）确定设计对象，收集声音素材的过程

**设计对象：城市公园湖畔步道 · 清晨（雨后初晴）**

一条沿湖的石板步道，左侧是成片的落羽杉和水杉林，右侧是湖面。时间为工作日清晨 6:30 前后，游客尚未涌入。（场景照片见附录）

**选择该场景的理由**：

1. **频段层次干净**——树叶摩擦是高频宽带噪声，湖水拍岸集中在中低频，远处城市嗡鸣落在超低频，三层不冲突；
2. **空间纵深明确**——构成由近及远的四层距离，声音远近关系可被真实表达；
3. **事件辨识度高**——鸟鸣、水鸟起飞、阵风扫叶、自行车铃彼此差异极大；
4. **天然对应 2D + 3D 架构**——这一点决定了后续全部技术选型。

**声景分层与素材需求**：

| 层 | 内容 | 功能 | 资产 |
| --- | --- | --- | --- |
| 基底 L1 | 风穿树冠 | 空间高度与包围感 | `amb_parklake_loop_01` |
| 基底 L2 | 湖水轻拍石岸 | 空间实体与空旷感 | （同上，混合） |
| 基底 L3 | 远处城市低频嗡鸣 | 交代城市地理属性 | （同上，混合） |
| 事件 A | 鸟鸣短句 | 近处生命感 | `sfx_bird_chirp_01~03` |
| 事件 B | 水鸟起飞 | 中距离突发动态 | `sfx_water_bird_splash_01~03` |
| 事件 C | 阵风扫叶 | 打破时间均匀性 | `sfx_leaves_gust_01~03` |
| 事件 D | 远处自行车铃 | 人文标记 + 定位验证 | `sfx_bicycle_bell_01~03` |

合计 **1 条基底 + 4 类共 12 个随机声**。作业最低要求为"1 条基底 + 3 个随机声"，此处做 12 个是因为 **Random Container 需要每类至少 3 个变体**才能有效避免重复感。

**声音素材的收集方式**

主要采用 **AIGC 生成 + 音源素材整合** 的混合方式：

- **间断随机声（12 个）**：用 ElevenLabs 的 Sound Effects 工具生成。提示词按"声源 + 视角距离 + 声学环境 + 时长 + 排除项"五要素构造，每个资产生成 3–5 次后按"无音乐性、无人声、形态正确、无 AI 瑕疵"四条标准筛选。完整提示词清单见 `final/docs/02`。
- **基底环境声（1 条）**：取自 Pixabay Sound Effects 的免费录音素材（`ambience-wind-blowing-through-trees`），因为长时、连续、无音乐性的环境声恰是当前音频生成模型最薄弱的环节，而真实录音自带空间感与微动态。

> **这一取舍本身是一处设计判断**：不同性质的声音用不同手段——真实素材提供空间真实感，AIGC 提供变化量与生产效率。

**基底素材的客观测量**（而非凭感觉选材）

对下载的基底素材做了量化分析（MP3 帧解析 + WASM 解码 + FFT）：

| 指标 | 实测值 | 判断 |
| --- | --- | --- |
| 采样率 / 声道 / 编码 | 48000 Hz / 立体声 / 256 kbps CBR | ✅ 原生 48k，无需重采样 |
| 左右声道相关性 | 0.786 | ✅ 有真实立体声宽度 |
| 动态范围（5%–95% 分位） | 8.31 dB | ✅ 极稳，适合做基底 |
| 瞬态事件（>6 dB 孤立峰） | 仅 2 个（各约 6.3 dB） | ✅ 无鸟叫等人声/事件特征 |
| 峰值电平 | -31.14 dBFS | ⚠️ 偏低 25 dB，需增益补偿 |
| 频段能量 | <200 Hz 占 71.3%，2–8 kHz 仅 5.4% | ⚠️ 偏低频，需高频补偿或叠加高频层 |

据此确定了两项后期处理：**整体增益 +25 dB**（峰值提升至 -6 dBFS）、**100–120 Hz 高通 + 2–6 kHz 温和提升**。完整分析记录见 `final/assets/amb-01-源素材分析.md`。

**选材的一条准则**：基底层不允许出现可辨识的离散事件。因为基底要 40 秒循环播放，任何能被记住的声音都会周期性暴露；且它还会与 3D 定位的事件层互相掩蔽。

#### （2）剪辑素材，导出资产的过程

**工具**：Reaper 7.86。工程采样率设为 **48000 Hz**、位深 **24 bit**。

**基底的无缝循环处理**（本次技术难度最高的一步）

目标：40 秒、首尾相接听不出接缝、可无限循环。

做法是"**尾巴叠头**"交叉淡化：

1. 从 90 秒源素材中选一段音色均匀、无突发事件的 42 秒；
2. 取该段最后 2 秒，复制粘贴到段落开头，形成 2 秒重叠；
3. 对重叠区做 2 秒等功率交叉淡化：复制段淡出、原始段淡入；
4. 从段落起点渲染 40 秒。

这样文件开头是"上一轮的结尾"淡入、结尾是"下一轮的开头"淡出，首尾相接时能量连续，循环处听不出接缝。

`⬜ 待填`：实际选用的起止时间、循环测试结论（是否一次成功、返工几次、最终淡化时长）。

**随机声的处理**：12 个随机声统一裁掉首尾静音（AI 素材常带 0.2–0.5 秒静音，会在 Wwise 中造成触发延迟感）→ 加 2–5 ms 淡入淡出防爆音 → 60 Hz 高通 → 归一化至峰值 -3 dBFS。

**导出参数**：

| 项目 | 值 |
| --- | --- |
| 采样率 | 48000 Hz |
| 位深 | 24 bit PCM |
| 声道 | Stereo |
| 容器 | WAV |

**自动化校验**：为避免人工确认格式出错，编写了 WAV 头解析脚本 `final/tools/check-wav.js`（无第三方依赖，直接读 RIFF/fmt 块），逐文件校验采样率、位深、声道数、时长，并检查基底是否 >30 秒、随机声是否 ≥3 个。

#### （3）使用 Wwise 的情况

**环境**：Audiokinetic Launcher + **Wwise 2025.1.11.9262**，工程名 `ParkLakeAmbience`（不含中文），平台 Windows。

**工程层级结构**：

```
Default Work Unit
├── Ambience
│   └── amb_parklake_loop_01        （Sound SFX，2D，Loop）
└── SFX
    ├── RC_BirdChirp                （Random Container × 3 变体，3D）
    ├── RC_WaterBird                （Random Container × 3 变体，3D）
    ├── RC_LeavesGust               （Random Container × 3 变体，3D）
    └── RC_BicycleBell              （Random Container × 3 变体，3D）
```

**（a）基底的持续循环**

对 `amb_parklake_loop_01` 勾选 **Loop** 属性使其无限循环，并确认该属性未被父级 override，Playback Limit 保持 1。

**基底刻意不启用 3D、不绑定 Attenuation**——它的功能是包围听者，不应有方位。

**（b）Random Container 随机触发**

四类随机声各建一个 Random Container，容纳各自 3 个变体，Random Type 采用 **Shuffle（洗牌）** 并启用避免连续重复。相比纯随机，洗牌模式在只有 3 个变体时更能避免"刚响过又响一遍"。

**（c）3D Positioning 与距离衰减**

四个 Random Container 均开启 **3D 定位**，并共同绑定 Attenuation ShareSet `ATT_Park_3D`：**Max Distance = 50 m**，曲线采用 **Logarithmic**。效果为听者在 0–5 m 内几乎满音量，10 m 起明显衰减，50 m 外基本不可闻。

**定位策略的对照**——这正是本设计的核心表达：

| 对象 | 定位 | Attenuation | 设计理由 |
| --- | --- | --- | --- |
| 基底环境声 | **2D** | 不绑定 | 包围感，无方位 |
| 4 个 Random Container | **3D** | `ATT_Park_3D` | 事件有明确来向与距离 |

**（d）Soundcaster 测试**

在 Soundcaster Session 中分别触发基底的 Play Action 与四类随机声，验证三点：基底循环无接缝、随机声每次换变体、在 Game Object 3D Viewer 中拖动听者位置能听到明显的距离变化。
