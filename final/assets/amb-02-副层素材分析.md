**主层的短板正是副层的长板**，这不是巧合，而是分层选材的正确做法：单条素材很难同时覆盖低频厚度与高频细节，分层叠加比一条素材硬调 EQ 效果好得多。

## ⚠️ 需要注意的问题：24 kHz 采样率

这条素材是 **MPEG2 / 24000 Hz**，意味着**内容被限制在 12 kHz 以内**（奈奎斯特频率）。

影响评估：

| 方面 | 影响 |
| --- | --- |
| 2–8 kHz（树叶沙沙主战场） | ✅ **完全覆盖**，62.2% 能量在这里，是有效内容 |
| 8–12 kHz | ✅ 有内容（12.4%），是主要空气感来源 |
| 12 kHz 以上 | ❌ 无内容，转 48 kHz 也补不回来 |
| 格式合规性 | ✅ Reaper 导出 48 kHz 后完全符合作业要求 |

**结论：可以接受。** 我们最需要的是 2–8 kHz 的沙沙质感，这部分完整保留。缺的只是 12 kHz 以上的"空气感"，在环境声基底里权重很低。

**但有一个风险要试听确认**：24 kHz 的 MP3 在高频段编码质量较弱，被当作"清脆层"放大后，可能出现**"水声感 / 塑料味的咝咝声"**而不是自然的树叶摩擦。叠加后请重点听这一项，若明显不自然，需换一条 44.1/48 kHz 的树叶素材。

## 后期处理建议（Reaper 中）

### 1. 重采样

工程采样率设为 48000 Hz 后导入，Reaper 会自动转换。**这属于上采样，不增加信息，只保证格式一致**。

### 2. 频段分工（关键）

副层做 **1.5 kHz 高通**，切掉 200 Hz–1.5 kHz 与主层重叠的部分，只保留纯"树叶沙沙"：

| 层 | 频段角色 | 处理 |
| --- | --- | --- |
| 主层 | 低频厚度（<1.5 kHz 为主） | 100–120 Hz 高通，2–6 kHz +2~3 dB |
| **副层** | 高频细节（>1.5 kHz 为主） | **1.5 kHz 高通**，不做其他提升 |

### 3. 电平配比

| 层 | 原始 RMS | 目标处理 | 最终 RMS |
| --- | --- | --- | --- |
| 主层 | -48.20 dBFS | **+25 dB** | ≈ -23.2 dBFS |
| 副层 | -31.48 dBFS | **约 -8 dB**（高通后再降约 1 dB） | ≈ -40 dBFS |

即副层最终比主层低约 **15 dB**。这是起点，请按听感在 **±3 dB** 内微调。

**判断标准**：树叶沙沙清晰可辨、有质感，但**不抢过风声主体**。副层一旦压过主层，整个环境声会变成"干燥的纸张摩擦感"，失去空间厚度。

### 4. 选段

| 窗口 | 说明 |
| --- | --- |
| **47.0 – 87.0 s** | 检出 0 个瞬态事件，能量变异系数 27.6% |
| 避免 17 s 附近 | 峰值 -3.99 dBFS，全曲最强风阵 |

副层是纹理层且最终会被衰减 15 dB，对动态起伏的容忍度比主层高；风阵带来的起伏在低电平下反而增添自然感。

## 叠层后的整体验证

合成基底导出前，用 `final/tools/check-wav.js` 确认格式，另需人工确认三点：

1. **循环处无接缝**——用 `docs/03` 的"尾巴叠头"法，在**叠加完成后的整体**上做，不要对两层分别做循环；
2. **无塑料感**——重点听 2–12 kHz 是否有非自然的咝咝声；
3. **无浑浊**——若 200–500 Hz 糊成一团，说明副层高通不够，把高通提到 2 kHz 再试。
