# AMB 基底处理记录

> 记录基底双层素材的实际处理参数与验证结果，可直接引用进期末报告「剪辑素材，导出资产的过程」一节。

## 处理链路

```
源素材（MP3）
  ├─ 主层 traian1984-ambience-wind-blowing-through-trees  (48 kHz / 90.24 s)
  └─ 副层 freesound-community-noise-of-wind-in-tree-foliage (24 kHz / 181.90 s)
        ↓ 副层重采样 24k → 48k（零插值 + 127 抽头加窗 sinc FIR，截止 11 kHz）
        ↓ 各自按窗口切片 + "尾巴叠头"等功率交叉淡化 2 s → 精确 40 s
        ↓ 滤波（主层：110 Hz 四级高通 + 2.5 kHz 高架 +2.5 dB；副层：1.5 kHz 四级高通）
        ↓ 电平配平（主层峰值 -6 dBFS；副层 RMS 比主层低 15 dB）
        ↓ 写出 24 bit PCM / 48 kHz / Stereo WAV
```

## 参数明细

| 项目 | 主层 | 副层 |
| --- | --- | --- |
| 源采样率 | 48000 Hz | 24000 Hz → 重采样至 48000 Hz |
| 窗口起点 | **2.0 s** | **47.0 s** |
| 取用长度 | 42.0 s（40 s + 2 s 尾巴） | 42.0 s（40 s + 2 s 尾巴） |
| 交叉淡化 | 2 s 等功率（sin/cos） | 2 s 等功率（sin/cos） |
| 高通 | 110 Hz，两级级联（≈24 dB/oct） | 1500 Hz，两级级联（≈24 dB/oct） |
| 高架提升 | 2500 Hz，+2.5 dB，S=1 | 无 |
| 电平 | 峰值归一至 **-6.00 dBFS** | RMS 比主层低 **15.0 dB** |
| 输出 | 40.000 s / 48 kHz / 24 bit / stereo | 同左 |

> **关于"为什么可以分层分别做循环"**：交叉淡化与滤波都是线性运算，因此
> `crossfade(主) + crossfade(副) ≡ crossfade(主 + 副)`。
> 两层使用完全相同的窗口长度与淡化时长，所以分开处理后叠加，与"先混再循环"在数学上等价。

## 仍需人工完成的部分

1. **在 Reaper 中叠加并导出最终资产**（`amb_parklake_loop_01.wav`）——作业要求导出来自 DAW，且混音平衡需要听觉判断；
2. **试听三项检查**：① 2–12 kHz 有无"塑料感/水声感"的咝咝声（24 kHz 源的编码限制）；② 200–500 Hz 是否浑浊；③ 循环连听三遍有无可听出的周期性；
3. 若副层听感不足，提高 3–6 dB；若沙沙声盖过风声或发干，降低 3–6 dB。
