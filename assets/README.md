# assets · 辅助材料目录

本目录用于存放调研报告的图片、视频等辅助材料。

> **说明**：报告中的架构图与流程图目前使用 **Mermaid** 代码块内嵌在 `.md` 文档中，GitHub 网页端可直接渲染，无需额外图片文件。只有在需要更复杂的手绘示意图或截图时，才需要在本目录补充图片。

## 内容规划

| 文件（建议命名） | 类型 | 说明 |
| --- | --- | --- |
| `01-工具实测截图.png` | 图片 | 若实际试用了某个 AI 音频工具，可放生成界面截图作为过程佐证 |
| `02-频谱对比.png` | 图片 | mini pipeline 实验中基准音效与生成变体的频谱对比 |
| `demo-*.wav` | 音频 | 音效变体生成实验的产物，作为第 8 节实验的佐证材料 |

## 在报告中引用

Markdown 中按相对路径引用即可：

```markdown
![mini pipeline 实验的频谱对比](../assets/02-频谱对比.png)
```

## 注意

- 大体积视频文件（>100 MB）会超出 GitHub 单文件限制，建议改用外部链接或 Git LFS。
- 引用第三方素材时请一并注明来源与授权方式。
