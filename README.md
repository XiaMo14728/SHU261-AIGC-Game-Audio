## 成果速览

调研报告围绕两条轴展开：

**按内容方向（做什么）**

- **Voice**：本地化配音、海量边缘台词、原型对白；行业"分层使用"共识与 2025 年 AI 配音争议
- **Music**：AI 生成成品曲 vs AI 生成素材 + 中间件实时编排的两条路线对比
- **SFX**：Foley 自动拟音、程序化变体生成、占位资源；音效是 AIGC 落地最快的方向

**按生成模式（怎么生成）**

- Text-to-Music / Text-to-Audio
- Text-to-Speech + 语音克隆
- Video-to-Audio（Foley 自动拟音）
- Text-to-Video（原生音频）
- Audio-to-Audio（变体、风格迁移、分离修复）

**核心结论**

1. AIGC 的现实定位是"素材生产与变体供应商"，而非"艺术决策者"
2. 离线生成 + 人工精修 + 中间件组织，是当前最务实的工程组合
3. 素材从稀缺变为过剩后，Wwise / FMOD 的"组织与响应"能力重要性上升
4. 最大的风险不是技术，而是权利与合规
5. 评估 AIGC 音频方案应看"平均可用率 + 修复成本"，而非"最佳样例"
