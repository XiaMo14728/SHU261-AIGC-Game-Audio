已安装的 MinGit 可直接使用（在 PowerShell 中执行）：


### 如需修改作者信息

配置身份：

```powershell
$git  = "$env:USERPROFILE\Downloads\tools\MinGit\cmd\git.exe"
$repo = "$env:USERPROFILE\Downloads\SHU261-AIGC-Game-Audio"

& $git -C $repo config user.name  "新的姓名"
& $git -C $repo config user.email "新的邮箱"
```

重写已有提交的作者信息。**注意：`git rebase --root --exec` 与 `git filter-branch` 在本机行不通**——它们需要 `sh.exe`，而本机环境禁止程序创建命名管道，`sh` 会以 `couldn't create signal pipe, Win32 error 5` 失败。因此这里改用**纯 git 内建命令**实现（`cherry-pick` + `--reset-author`，不需要 shell）：

```powershell
$git  = "$env:USERPROFILE\Downloads\tools\MinGit\cmd\git.exe"
$repo = "$env:USERPROFILE\Downloads\SHU261-AIGC-Game-Audio"

# 备份，便于回滚
& $git -C $repo branch -f backup-before-rewrite main

$commits = @(& $git -C $repo rev-list --reverse main)   # 旧 → 新

& $git -C $repo checkout --detach $commits[0]
& $git -C $repo commit --amend --no-edit --reset-author

for ($i = 1; $i -lt $commits.Count; $i++) {
  & $git -C $repo cherry-pick -n $commits[$i]
  & $git -C $repo commit -C $commits[$i] --no-edit --reset-author
}

& $git -C $repo branch -f main HEAD
& $git -C $repo checkout main

# 验证：作者应只有一种，且内容与备份完全一致（diff 无输出）
& $git -C $repo log --format="%h  %an <%ae>  %s"
& $git -C $repo diff backup-before-rewrite main --stat
& $git -C $repo branch -D backup-before-rewrite     # 确认无误后删除备份
```

> 一旦推送到 GitHub，就不要再改写历史，否则需要强制推送（`--force`）才能覆盖远程记录。原则是"**先定作者、再推送**"。

同时建议配置全局身份（供以后所有仓库使用；这会写入 `C:\Users\<你的用户名>\.gitconfig`）：

```powershell
& $git config --global user.name  "你的姓名"
& $git config --global user.email "你的邮箱"
```
