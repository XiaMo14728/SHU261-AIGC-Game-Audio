## 第 1 步：安装工具

**推荐路线：GitHub Desktop**（图形化，作业要求中明确允许）

1. 访问 https://desktop.github.com/ 下载并安装 GitHub Desktop；
2. 首次启动时登录 GitHub 账户；若还没有账户，先在 https://github.com/signup 注册（建议用户名使用拼音 + 数字，避免使用真实姓名全拼）；
3. GitHub Desktop 自带 Git 运行时，安装后无需再单独安装 Git。

**命令行路线（可选，便于理解原理）**

1. 访问 https://git-scm.com/download/win 下载 Git for Windows；
2. 安装后打开 PowerShell，执行 `git --version` 确认安装成功；
3. 配置身份：

```bash
git config --global user.name "<姓名或拼音>"
git config --global user.email "<你的邮箱>"
```

## 第 2 步：创建公开仓库

**用 GitHub Desktop**

1. 打开 GitHub Desktop → `File` → `New repository...`
2. 填写：
   - **Name**：`SHU261-AIGC-Game-Audio`
   - **Description**：`2026 SHU 基础实践 · 平时作业：AIGC 在游戏音频设计中的应用`
   - **Local path**：`C:\Users\XiaMo\Downloads`
   - 勾选 **Initialize this repository with a README**（本项目已有 README，可不勾选）
3. 点击 `Create repository`；
4. 点击右上角 `Publish repository`，**务必取消勾选 `Keep this code private`**，然后发布。

> ⚠️ **公开是硬性要求**。如果已经创建成私有仓库，可在 GitHub 网页端进入 `Settings` → 页面底部 `Danger Zone` → `Change repository visibility` → `Change to public`。

**用命令行**

```bash
cd "C:\Users\XiaMo\Downloads\SHU261-AIGC-Game-Audio"
git init
git branch -M main
git add .
git commit -m "docs: 添加 AIGC 游戏音频调研报告"
# 先在 GitHub 网页端创建空仓库（不要勾选 Add README），然后：
git remote add origin https://github.com/<GitHub用户名>/SHU261-AIGC-Game-Audio.git
git push -u origin main
```
